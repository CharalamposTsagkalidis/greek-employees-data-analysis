This repository contains data from a survey conducted for my MBA thesis in Information Systems at the University of Western Macedonia. The survey explores work environment quality, organizational structure, and management practices in Greece, targeting professionals in technology and consulting companies. The included Excel file contains anonymized data with no sensitive information.

Analysis Performed Using R

T-test

Linear regression

Boxplots

Normality checks

Cronbach’s alpha
